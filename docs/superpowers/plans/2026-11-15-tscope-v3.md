# T-SCOPE v3 Implementation Plan

> **For agentic workers:** Use the parallel-agent skill for independent files and
> verification-before-completion for the integrated release.

**Goal:** Deliver a runnable, auditable v3 and launch matched multi-account Kaggle training.

**Architecture:** Preserve v2. Add a separate six-variant v3 protocol, paper-derived
reference, strict train/eval runner and quota-aware pinned worker launcher.

**Tech Stack:** Python 3.11, PyTorch/torchvision, NumPy/SciPy, ffmpeg/libx265, Kaggle SDK.

**Spec:** `docs/superpowers/specs/2026-11-15-tscope-v3-design.md`.

## Global Constraints

- No fabricated v3 results or changes to historical v2 benchmark numbers/weights.
- x265 only; teacher weights required; credentials excluded from source and logs.
- Same data, seed, training budget and initialization within matched comparisons.
- Separate account replicates; no cross-seed soups.

## Review Focus

- Empty/missing datasets and missing pretrained teachers must fail before training.
- Nonmonotone AP and no common accuracy interval must be explicit, never extrapolated.
- A timed-out training job must preserve progress without claiming convergence.
- Worker source must match the exact published revision, even for training.
- Quota failures and partial account availability must not scramble job identity.
